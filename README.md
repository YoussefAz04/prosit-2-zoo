# Prosit 2 — Gestion d’un zoo en Java

Instructions 5 à 9 : classes Animal et Zoo, objets, constructeurs paramétrés, displayZoo() et redéfinition de toString().

Il s’agit de la version finale du Prosit 2 après introduction des constructeurs paramétrés.

## Prérequis

JDK 17 ou supérieur. Maven pour les commandes ci-dessous, ou IntelliJ IDEA pour lancer directement la méthode main.

## Exécution dans IntelliJ IDEA

1. Extraire cette archive.
2. Ouvrir le fichier `pom.xml` comme projet Maven.
3. Choisir un JDK 17 ou supérieur dans les paramètres du projet.
4. Lancer la méthode `main` de `ZooManagement`.

## Exécution avec Maven

Depuis le dossier contenant `pom.xml` :

```bash
mvn compile
java -cp target/classes ZooManagement
```

## Dépôt GitHub

Ce projet est autonome et doit être déposé séparément des autres prosits.
Placer `src`, `pom.xml`, `README.md` et `.gitignore` à la racine du dépôt.
Ne pas déposer l’archive ZIP ni les dossiers générés `target`, `out` et `.idea`.
